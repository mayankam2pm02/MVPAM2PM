# WhatsApp Web Sync Extension

This helper extension bridges your active browser session on **web.whatsapp.com** with **Mr. Manager**.

## How to install:

1. Open **Chrome** and navigate to `chrome://extensions/`.
2. Toggle on **Developer mode** in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select this directory (`whatsapp-extension`).
5. Open `https://web.whatsapp.com` in a new tab (or reload it if already open) and ensure you are logged in.
6. The Mr. Manager dashboard will automatically detect the active session!
